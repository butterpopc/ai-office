# D-001 사무실 본부는 새 저장소로 분리

- 확정일: 2026-10-29
- 결정자: 사용자

## 결정

- AI 사무실의 공통 규칙·진행판·템플릿은 **새 저장소(이 본부)** 에 둔다.
- `AI-ART_taskforce`는 진행 중인 작업이므로 **본부 작업 중에 수정하지 않는다.**

## 배경

- `AI-ART_taskforce`에서 컨트롤 타워(Claude) + 실무(GPT) + 조사(Gemini) + 저장소 구조가 2026-10-26부터 실제로 운영됨.
- 같은 날 GPT가 「AI 사무실 조직·인선·운영 설계안 v0.1」을 구글 드라이브에 작성. 컨트롤 타워 검토 의견: 이미 돌아가는 구조를 반영하지 않고 새로 설계했으므로, 실제 운영 구조를 일반화하는 쪽이 근거가 있다.
- 개선 제안(PR 방식, `[GPT]` 표시, 드라이브 직접 읽기)을 기존 저장소에 바로 적용하면 진행 중인 작업을 해칠 수 있어, 사용자가 새 저장소에서 하기로 결정.
