# B-001 [실무] PR 방식 시범

- 담당: GPT
- 작성: 컨트롤 타워(Claude), 2026-10-29
- 읽을 것: README.md, STATUS.md, RULES.md 2번, 이 지시서

## 목적

GPT가 **브랜치 + PR** 방식으로 제출할 수 있는지 확인한다. 내용보다 **절차가 되는지**가 핵심이다.

## 할 일

1. 브랜치 `gpt/B-001-pr-test`를 만든다.
2. 그 브랜치에 `handoffs/2026-10-29_gpt_PR시범.md` 파일을 만든다. 내용:
   - 이 지시서를 읽고 이해한 작업 순환을 3줄로 요약
   - 네(GPT)가 이 저장소에서 할 수 있는 것 / 할 수 없는 것 (브랜치 생성, PR 생성, 댓글 읽기 등). 각각 `실측` 또는 `미확인` 표시
3. 커밋 메시지: `[GPT] B-001: PR 방식 시범`
4. main으로 PR을 연다. 본문은 자동 양식을 채운다.
5. **머지하지 않는다.**

## 안 되는 단계가 있으면

- 브랜치나 PR을 못 만들면, 어디서 막혔는지 그대로 사용자에게 알린다. 우회하려고 main에 직접 올리지 않는다.

## 완료 기준

- PR이 열려 있고, 본문에 인계 요약이 채워져 있고, 커밋 메시지에 `[GPT]`가 있다.
