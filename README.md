# AI 사무실 — 본부

여러 AI(Claude · GPT · Gemini)가 사용자 한 명의 일을 나눠 맡는 **AI 사무실의 본부 저장소**입니다.
여기에는 사무실 전체의 운영 규칙, 진행판, 새 프로젝트용 템플릿이 있습니다.
개별 프로젝트의 실제 작업은 각 프로젝트 저장소에서 합니다.

> 이 구조는 `AI-ART_taskforce`(2026-10-26~)에서 실제로 돌려 본 방식을 일반화한 것입니다.
> 그 저장소는 진행 중인 작업이므로 이 본부에서 수정하지 않습니다 ([D-001](decisions/D-001_본부_저장소_분리.md)).

---

## 🤖 처음 온 AI라면 이 순서로 읽으세요

1. **이 README** — 역할과 작업 순환
2. [`STATUS.md`](STATUS.md) — 사무실 전체 진행판 (프로젝트 목록 포함)
3. [`RULES.md`](RULES.md) — 양식과 규칙 (**반드시 지킬 것**)
4. 사용자가 지정한 지시서 1개 (`briefs/` 또는 프로젝트 저장소의 `briefs/`)

필요할 때만: [`FACTS.md`](FACTS.md) (운영에 관한 검증된 사실), [`decisions/`](decisions/) (확정된 결정)

> 전체 대화 기록을 요구하지 마세요. 판단에 필요한 정보는 위 파일들에 있습니다.

## 역할

| 역할 | 담당 | 하는 일 | 하지 않는 일 | 저장소 권한 |
|---|---|---|---|---|
| **사용자** | 사람 | 최종 결정, 취향 판단, PR 승인, AI 간 전달 | — | 전부 |
| **컨트롤 타워** | Claude | 계획, 지시서 작성, 결과 검증·판정, PR 검토, 기록 | 판정 없이 계획 변경 | 읽기·쓰기 |
| **실무** | GPT | 지시서에 따른 작업 → **PR로 제출** | STATUS·decisions·RULES 직접 수정, 계획 임의 변경 | 읽기·쓰기 (브랜치·PR) |
| **조사** | Gemini | 조사 지시서에 따른 조사 → [조사 보고] | 취향 판단, 지시 범위 밖 조사 | 읽기 전용 |

역할 배치는 `AI-ART_taskforce`의 D-003·D-004에서 실제로 운영해 본 배치를 그대로 가져왔습니다.
바꾸려면 같은 과제로 비교한 근거를 붙여 `decisions/`에 새 결정으로 올립니다 (RULES 4번).

## 작업 순환

**실무 (GPT) — PR 방식**

```
① 컨트롤 타워: briefs/ 에 지시서 작성
        ↓
② 사용자: GPT에게 "README·STATUS·B-번호 읽고 해줘"
        ↓
③ GPT: 새 브랜치에서 작업 → PR 생성 (본문 = 인계 요약 양식, 자동으로 채워짐)
        ↓
④ 사용자: 컨트롤 타워에 "PR #번호 올라왔어"
        ↓
⑤ 컨트롤 타워: PR 읽고 [판정]을 PR 댓글로 → 통과면 사용자에게 승인 요청
        ↓
⑥ 사용자: Merge 버튼 클릭 → 컨트롤 타워가 STATUS 갱신
```

**조사 (Gemini)**

```
① 컨트롤 타워: briefs/ 에 조사 지시서 작성
        ↓
② 사용자: Gemini에게 "README·STATUS·B-번호 읽고 조사해줘"
        ↓
③ Gemini: [조사 보고]를 구글 드라이브에 저장 (파일명 R-번호_제목)
        ↓
④ 사용자: 컨트롤 타워에 "R-번호 드라이브에 올라왔어" (붙여넣기 불필요)
        ↓
⑤ 컨트롤 타워: 드라이브에서 직접 읽고 핵심 주장 확인 → research/ 저장, 검증된 사실은 FACTS.md로
```

사용자가 할 일은 **전달 한 마디와 승인 버튼**으로 줄이는 것이 목표입니다.

## 폴더 구조

| 경로 | 내용 | 수정 권한 |
|---|---|---|
| `STATUS.md` | 사무실 진행판 + 프로젝트 목록 | 컨트롤 타워 |
| `RULES.md` | 운영 규칙과 양식 | 컨트롤 타워 (사용자 승인) |
| `FACTS.md` | 운영에 관한 확인된 사실 (AI별 권한·한계 등) | 컨트롤 타워 |
| `decisions/` | 확정된 결정 `D-번호_제목.md` | 컨트롤 타워 (사용자 결정 기록) |
| `briefs/` | 지시서 `B-번호_제목.md` | 컨트롤 타워 |
| `handoffs/` | 인계 요약 `날짜_AI이름_주제.md` | GPT(PR) · 컨트롤 타워 |
| `research/` | 조사 보고 `R-번호_제목.md` | 컨트롤 타워가 기록 |
| `template/project/` | 새 프로젝트 저장소용 템플릿 | 컨트롤 타워 |
| `.github/pull_request_template.md` | PR 본문 자동 양식 (인계 요약) | 컨트롤 타워 |

## 새 프로젝트 시작하기

1. 사용자: GitHub에서 빈 저장소 만들기
2. 컨트롤 타워: `template/project/`의 파일을 복사해 채우고, 이 본부 `STATUS.md`의 프로젝트 목록에 추가
3. 공통 규칙은 이 본부의 `RULES.md`를 따르고, 프로젝트 고유 규칙만 프로젝트 저장소에 적습니다.
