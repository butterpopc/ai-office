# B-001 — PR 방식 시범

- 담당: GPT
- 작업일: 2026-10-29
- 지시서: [B-001](../briefs/B-001_PR방식_시범.md)
- 작업 브랜치: `gpt/B-001-pr-test`

## 이해한 작업 순환 — 3줄

1. 컨트롤 타워(Claude)가 지시서를 작성하면 사용자가 전달하고, GPT는 README·STATUS·규칙·지정 지시서를 읽는다.
2. GPT는 전용 브랜치에서 작업하고 `[GPT]` 커밋과 인계 요약을 채운 PR로 제출하며 main에는 직접 커밋하지 않는다.
3. 컨트롤 타워가 PR을 검토·판정하고, 통과 후 사용자가 머지하며 컨트롤 타워가 STATUS를 갱신한다.

## 이 저장소에서 확인한 기능

| 기능 | 확인 수준 | 근거·범위 |
|---|---|---|
| 지정 문서와 PR 템플릿 읽기 | 실측 | GitHub 연결 도구로 파일 본문을 읽었다. |
| 브랜치 생성 | 실측 | `main`에서 `gpt/B-001-pr-test` 생성 성공 응답을 받았다. |
| 브랜치에 파일 생성·커밋 | 실측 | 파일 생성 성공 후 브랜치에서 본문을 다시 읽었다. 생성 커밋: `35a7644a82aa8a79e503f06bf137f9932e43f0cc`. |
| PR 생성 | 실측 | [PR #1](https://github.com/butterpopc/ai-office/pull/1)을 main 대상으로 생성했다. |
| PR 본문·변경 내용 읽기 | 실측 | PR 조회로 인계 요약·diff·open 상태·미머지를 확인했다. |
| PR 댓글 조회 | 실측 | 댓글 조회 호출은 성공했고 현재 빈 목록을 반환했다. 실제 댓글 본문 읽기는 댓글이 없어 미확인이다. |
| 댓글 작성·리뷰 제출 | 미확인 | 이번 지시서에는 필요하지 않아 시험하지 않는다. |
| PR 머지 | 미확인 | 사용자 지시와 RULES 2에 따라 시도하지 않는다. |

## 이번 작업에서 하지 않는 일

main 직접 커밋, PR 머지, STATUS.md·RULES.md·decisions/ 수정, 다른 프로젝트 저장소 수정, 추가 유료 서비스 사용은 하지 않는다. 이는 작업 범위·권한 제한이며 기술적 불가능을 뜻하지 않는다.
